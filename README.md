# Tidal to Apple Music

I have been on a journey to switch from Spotify to any other streaming service. Tidal has been my platform of choice for a few months, which has sadly been more of a nuisance than I expected. Therefore, I am looking to jump ship again, this time to Apple Music.

Switching platforms is always an annoying task, however, as I have done it a few times now. So, instead of paying for an app, or using someone else's code this time around, I've decided to dedicate my P:TS project to this.

The plan is to have an app with a GUI where playlist files can be entered, and then the app transfers those to Apple Music. 

I did a small amount of research, and it seems like the playlist files will have to be extracted externally (not through the app), but I will see if implementing it might be possible.
